# Atlas Decide

Choose from the requested outcome and context, honoring an explicit choice. Ask only when ambiguity changes the method. Read and follow the relevant references; combine methods when they serve complementary parts of the task.

| Mode | Need | Read and follow |
| --- | --- | --- |
| Probe | Challenge an idea conversationally | [Probe](references/probe/grill-me.md) |
| Record | Interview while recording decisions and vocabulary | [Record](references/record/grill-with-docs.md) |
| Map | Discover or resume a multi-session effort | [Map](references/map/wayfinder.md) |
| Query | Prepare questions for someone holding missing knowledge | [Query](references/query/to-questionnaire.md) |

When a bounded interview becomes multi-session discovery, offer Map and carry existing decisions and record links forward. Map needs a usable tracker contract. A questionnaire drafts communication; it does not send it.

Resolve skills required by the selected reference through the host. If a required capability is unavailable, explain the gap before proceeding with that method.
