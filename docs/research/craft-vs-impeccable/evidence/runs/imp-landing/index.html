How a piece is born

Seven stops, in order. Every room in the Desk is optional, and chat is always a complete alternative.

  1. Shower thought

    Ask in chat, or say “open the desk” and let it interview you.

  2. brief.md

    Every piece has one, and its first heading is the piece’s title. pnpm lint cries if it’s missing.

  3. The Desk

    Pick a vibe, gather references, plan beats against a track.

  4. Skill time

    The right skill takes over and runs its own process.

  5. Render

    Frames come out of code into renders/, which can always be rebuilt.

  6. QA

    Evidence goes in qa/. At checkpoints, Leonardo judges an interactive page and his notes come back in a format agents can read.

  7. Ship it?

    Only if Leonardo says so. Approved finals live in the piece’s final/ folder with a checksum manifest.

The Desk

A live local studio in your browser: an interview, a Lobby of pieces, a catalog of every look the installed skills can make, and five rooms per piece.

It never runs a skill or a model itself. It writes plain files beside the piece, and agents do the work.

Get started

Node 22.12 or later and pnpm 11. Run these from the checkout.

  • pnpm install

    Install dependencies and let pnpm manage the links.

  • pnpm desk:start

    Find or start this checkout’s Desk and print its URL.

  • pnpm studio:doctor

    Check your tools. ffmpeg-full, anyone?

  • pnpm lint

    The bouncer: briefs, media and studio checks.
