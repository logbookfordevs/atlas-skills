# Logbook Atlas: current stack

The fresh-start review supersedes the earlier umbrella-first proposal. The authoritative decisions and implementation state are in [Atlas fresh start](atlas-fresh-start.md).

## Local packages

- HTML UI: Wireframe and Model.
- Atlas To Spec and Atlas To Tickets: separate preserved, patched upstream adaptations.
- Atlas Review: Code, Static and Motion.
- Atlas Craft: Color, Type and Layout.
- Atlas Motion: Animate and Fluid.
- Writing for Humans: existing authored method with verbatim Stop Slop.
- Tracking Implementation, Team Up and manual Animated-Driven Frontend: independent authored utilities.
- Atlas Setup: manual dependency preparation.

Decide, Design and Specify are retired from active distribution. The already implemented retirements remain in place. Unchanged independent skills are recommended from upstream rather than copied into Atlas. AFK CLI and Profile Use belong to AFK and are mentioned as companions; Compass is excluded for now. Tracking refinement and the possible public website/installer are deferred.

## Maintenance

The [source manifest](../../sources/composition.json) records immutable source revisions, complete selected resource trees, licenses, patches and consumers. The [upstream updater](../authoring/upstream-updates.md) detects drift, opens or updates review issues and prepares reviewed revisions locally. Adoption and merging are deliberate. The daily workflow is not active until published on the default branch.

Changes are local, uncommitted and unpublished. No installed personal skills or external issues were changed.
