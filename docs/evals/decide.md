# Atlas Decide behavioral evaluation

These are observable acceptance cases, not completed model trials. Record host, model, tools, inputs and actual results. Do not assert exact prose.

| Request | Expected behavior |
| --- | --- |
| Challenge this idea; no documents | Probe (Grill Me); independent Grilling; conversational outcome. |
| Sharpen this architecture and record decisions | Record (Grill with Docs); Grilling and Domain Modeling; applicable ADR/glossary records. |
| Settle frontend direction with visible alternatives | Shape: design interview, meaningful visible alternatives, explicit selection or open choice, and durable visual commitment. |
| Shape completes and artifacts are requested | Carry selected references, fidelity contract and unresolved questions into Atlas Design without repeating settled choices. |
| Loose large discovery spanning sessions | Map (Wayfinder) after usable tracker context; chart destination and frontier, stop at charting boundary. |
| Resume this existing map/ticket | Map (Wayfinder) resume path; claim and work the named/available decision; respect one-ticket limit. |
| Implement these settled tickets | Recognize implementation rather than forcing a discovery map. |
| Explicitly choose Grill Me despite engineering context | Preserve explicit choice. |
| Ambiguous need between interview and map | One focused selection question if material; no repeated onboarding. |
| Interview grows beyond one session | Propose transition; carry decisions/open questions and document pointers, avoid repeating interview or unapproved tracker writes. |
| Required Grilling or tracker unavailable | Identify the actual missing prerequisite; no pretend invocation or silent weaker substitution. |
| Ordinary chat without invocation | Manual entry is not automatically selected. |
| Wayfinder research/prototype ticket | Use relevant independent capability only for its ticket type; preserve authority and human-participation boundary. |

Deterministic checks verify byte identity, provenance hashes, manual metadata, local links and generated parity. They do not prove routing or frontier-model quality.
