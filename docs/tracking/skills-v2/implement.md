# Tracking Implementation checkpoint

Atlas Implement has been removed. Tracking Implementation is an independent automatic authored package derived from the existing tracking method. Activate for requested tracking or resuming an existing tracked effort. It records the executor’s work rather than selecting a coding process, reuses its review evidence, and preserves user acceptance.

Implement Spec and Source Driven Development are independent catalog entries targeting their original upstream repositories. Their Atlas snapshots remain inactive evidence. Legacy AFK Implement is preserved unchanged, while its preview catalog entry is superseded. No personal installation is changed.

Package validation is recorded separately from pending live model trials. Changes remain local and unpublished.

The original commit/checkpoint policy is retained: useful green atomic intermediate checkpoints; implementation-owned changes committed before automated review; pre-commit user review for small or judgment-sensitive changes; warranted fixes validated and committed before acceptance. Local tracking remains outside commits by default.
