# HTML UI

Choose the mode from the requested deliverable, honoring an explicit mode.

| Mode | Need | Read and follow |
| --- | --- | --- |
| Artifact | Give a standalone HTML deliverable its visual direction: register, palette, type pairing, layout and theming | [Design Artifact](references/design/design-artifact.md) |
| Wireframe | Explore hierarchy, layout and task structure | [Wireframe](references/wireframe/html-wireframe.md) |
| Model | Show a polished mockup or a working product flow | [Model](references/model/html-prototype.md) |

Preserve agreed content and structure when moving between modes. Wireframe and Model read Design Artifact for visual direction as their methods describe; Wireframe's low fidelity and Model's fidelity, state and interaction rules stay authoritative. Design Artifact's closing publish offer belongs to Artifact mode only.
