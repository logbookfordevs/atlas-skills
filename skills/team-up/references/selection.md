# Selecting teammates

Use the smallest capable team where parallel work or fresh context helps. Prefer a fitting custom agent and respect its fixed settings; for configurable teammates, follow [Model preferences](model-preferences.md), choosing the family before the model and effort, or Mixed when no family is favored. Start at the earliest suitable supported pair for the task’s difficulty, uncertainty and stakes. Resolve actual model identifiers and choose settings deliberately, passing model and effort explicitly when supported. Check the result against the assignment’s acceptance criteria: escalate capability failures to the next suitable pair, resolve missing inputs or tool failures directly, and stop when the criteria hold. Explicit user choices and fixed custom-agent settings outrank defaults; resolve unavailable requested settings with the user. Disclose independence gaps and material departures, and favor task-specific evidence over default ordering.
