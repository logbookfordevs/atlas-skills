# Clean Room

Resolve the installed `clean-room` skill and read its instructions before preparing the brief. It owns decision framing, neutral evidence, the fresh-context requirement, verdict delivery and reruns. If it is missing, identify the dependency and offer installation before starting this mode.

Use Team Up’s [selection policy](selection.md) to choose the most capable available isolated reviewer for the decision, honoring requested models. Delegate to a child agent with no inherited conversation. Supply only the neutral brief and needed evidence; use a fresh child for every rerun. Opening a separate user-owned chat requires a request for that chat.

If the host cannot provide fresh context, report the capability gap and obtain the user’s choice before substituting another review method. Return Clean Room’s verdict unchanged and attribute it separately from any parent commentary.
