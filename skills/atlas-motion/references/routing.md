# Routing and ownership

| Upstream name | Atlas route |
| --- | --- |
| animate | [Animate](animate/animate.md) |
| apple-design | [Fluid](fluid/apple-design.md) |
| find-animation-opportunities | [Opportunities](opportunities/index.md) |
| review-animations | Atlas Review, Motion mode, when available |
| improve-animations | Atlas Review, Motion Audit mode, when available |
| animate-expo | External native method; not bundled or required for web motion |

Use local methods as references, including calls in supporting resources. Skip canned readiness replies when the user already supplied a task. Opportunities is read-only and hands off a selected proposal for planning or authorized construction. Its suggested Motion Audit planning command refers to Atlas Review; when that package is unavailable, provide the proposal and name the handoff gap.

Follow [Motion ownership](motion-ownership.md), preserving the distinction between feedback transitions and gesture-driven physics. Construction requires the user's requested implementation scope; a review or discovery request alone authorizes proposals only.
