# Atlas Craft

Choose from the requested outcome and context, honoring an explicit choice. Ask only when ambiguity changes the method. Read and follow the relevant references; combine methods when they serve complementary parts of the task.

| Mode | Need | Read and follow |
| --- | --- | --- |
| Color | Palette, tokens, rendered contrast or color usage | [Color](references/color/index.md) |
| Type | Font choice, sizing, wrapping and typographic detail | [Type](references/type/index.md) |
| Layout | Spacing, alignment, grouping, adaptivity or spatial RTL | [Layout](references/layout/index.md) |

Resolve better-colors, better-typography and better-layout calls to the corresponding bundled references. Preserve accepted identity and project foundations; new direction belongs to design work.

Resolve skills required by the selected reference through the host. If a required capability is unavailable, explain the gap before proceeding with that method.
