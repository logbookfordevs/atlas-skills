# Scope and ownership

Load linked methods when their rules are needed; a reference to another domain does not authorize an entire audit.

Domain severity sections contain the shared interface escalation rules. Apply those stated rules without launching cross-discipline orchestration. For a whole-interface audit or change review, offer Atlas Review's Interface mode when available. Review Animations and Improve Animations handoffs mean Atlas Review's Motion and Motion Audit modes; Find Animation Opportunities means Atlas Motion's Opportunities mode. These handoffs are separate requests, not requirements for completing a domain refinement.

Follow [Motion ownership](motion-ownership.md) for animation values, physics and gesture decisions, including when an upstream supporting example disagrees. Preserve accepted project identity and use its tokens where they meet behavior and accessibility requirements.

These instructions are web-interface methods. Native/Expo motion is outside the composition. Missing browser, screen-reader or runtime access limits verification; report that limit rather than claim the check passed.
