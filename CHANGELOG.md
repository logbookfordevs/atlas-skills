# Changelog

## 1.1.0

- Add Atlas Implement, Verify, Grill, Wayfinder, Explain, Retro and the manually invoked Atlas Mode entry point.
- Expand Review with adversarial, impact and static methods; Team Up with Arena, Swarm and optional model-family preferences.
- Add technical writing and Unslop guidance to Writing for Humans.
- Make Tracking local by default, add optional Audit Trail and specialist review selection, and restore interactive Plannotator handoff with parent ownership for delegated work.
- Bundle shared upstream methods and required supporting files with source receipts and replayable adaptations; keep unchanged complementary skills independently available.
- Refresh the website with method examples, source credits, and the public stack manifest with terminal and interface installation guidance.

Collection versions identify the Atlas repository as a whole. Source receipts identify the upstream revisions carried by individual packages.
