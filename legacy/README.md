# Legacy skills

On the Skills V2 branch, the previous authored `skills/` packages are preserved here without content changes. The two older legacy packages remain alongside them. `docs/migrations/skills-v2-archive.json` records the 66 moved files and their hashes.

This is an archive and reference for one-workflow-at-a-time migration, not a declaration that every independent skill will be absorbed. External catalog sources were not downloaded or removed. The live `main` branch retains its working catalog and original skill paths until a reviewed cutover.

Use explicit skill selection for branch previews; do not install every discoverable entry from this development branch. Archived packages keep their original entry metadata for preservation, so installers with recursive fallback discovery may list them. The Investigate preview was removed after review; independent Research is retained.
