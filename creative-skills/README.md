## Install and maintain

Copy the desired folder into your agent’s skill directory, or use the author’s installation instructions. Installation should include the entire folder, including assets, references and license.

These packages live separately from Atlas’s composed workflows in `skills/`. They are not registered in the Git-based upstream watcher or added to the recommended stack. April distributes them as downloads rather than Git repositories.

[provenance.json](provenance.json) records the imported download fingerprints and each original file’s SHA-256. All 21 files were checked against the supplied ZIP archives on import. Updates are manual: obtain a new author-provided distribution, review its changes and license, then refresh the fingerprints together. Keep attribution outside the original instruction files so the imported packages remain verbatim.
