# Atlas Figures

Present the full treatment menu below on every invocation, with a short description of each option. Recommend suitable treatments from the user's subject, medium and intended use, explaining the fit. Selection belongs to the user: wait for their choice before loading a method or building a figure. If the request already names a treatment, acknowledge that choice alongside the menu and proceed.

| Treatment | Character | Read after selection |
| --- | --- | --- |
| Hairline | Restrained isometric line art; one geometric idea responds to the pointer. | [Create](references/hairline-create/SKILL.md); for a supplied SVG, start with [Adopt](references/hairline-adopt/SKILL.md) |
| Anatomy | Detailed physical mechanisms that explain technical ideas through moving parts and a shared model. | [Anatomy](references/anatomy/SKILL.md) |
| Engraved Figures | Monochrome scientific plates, wireframes, stippled charts and research posters. | [Engraved Figures](references/engraved-figures/SKILL.md) |
| Teardown | Evidence-led technical illustrations, coherent views and exploded assemblies of objects or conceptual layers. | [Teardown](references/teardown/SKILL.md) |
| ISO-GLOW | Glowing isometric line art, interactive 3D objects, or solid-lit Lumen illustrations. | [ISO-GLOW](references/iso-glow/SKILL.md) |
| Colorfigures | Colourful, hand-inked objects with working mechanisms, rotation and see-through views. | [Colorfigures](references/colorfigures/SKILL.md) |

Follow the selected method and its conditional references. Its folder is the method's base directory for assets, scripts and examples; resolve `<skill folder>` there. Keep its visual grammar and engine together. Selecting several treatments means separate variants, unless the user requests a blend. A recommendation alone does not select a treatment.
